# Code-Travel: RPG of Languages

Обучающая RPG-игра, созданная для того, чтобы превратить изучение программирования в захватывающее приключение. Победите баги, решайте логические задачи и осваивайте новые языки, исследуя тематические острова.

## 🖥️ **Системные требования**

### **Минимальные требования:**
- **ОС:** Windows 10/11, Linux (Ubuntu 20.04+), macOS 10.15+
- **Процессор:** Intel Core i3 / AMD Ryzen 3 или эквивалент
- **Оперативная память:** 4 ГБ RAM
- **Видеокарта:** Встроенная графика с поддержкой OpenGL 2.1+
- **Свободное место:** 500 МБ на диске
- **Java:** Java Development Kit (JDK) 25 или новее

### **Рекомендуемые требования:**
- **ОС:** Windows 11, Linux (Ubuntu 22.04+), macOS 12+
- **Процессор:** Intel Core i5 / AMD Ryzen 5 или новее
- **Оперативная память:** 8 ГБ RAM
- **Видеокарта:** Дискретная графика с поддержкой OpenGL 4.0+
- **Свободное место:** 1 ГБ на диске
- **Java:** Java Development Kit (JDK) 25 с JavaFX 25

### **Автоматическая установка:**
- **Windows:** Запустите `setup-env.bat` для автоматической настройки Java и JavaFX
- **Portable версия:** Используйте `create-portable.bat` для создания автономной версии игры

## 📖 **Инструкция пользователю**

### **🚀 Быстрый старт:**
1. **Скачайте игру** и распакуйте архив
2. **Запустите `setup-env.bat`** (Windows) для автоматической настройки Java
3. **Запустите `build-and-run.bat`** для старта игры
4. **Войдите в систему** используя логин `admin` и пароль `123`

### **🎮 Игровой процесс:**
- **Выберите остров** - Java (коричневый), Python (зелёный) или C# (фиолетовый)
- **Создайте персонажа** - выберите имя, класс и характеристики
- **Исследуйте мир** - перемещайтесь по локациям и находьте квесты
- **Сражайтесь с багами** - отвечайте на вопросы программирования
- **Покупайте экипировку** - улучшайте своего персонажа в магазине
- **Сохраняйте прогресс** - игра автоматически сохраняет ваши достижения

### **💡 Советы:**
- **Изучайте руководство** - нажмите "РУКОВОДСТВО" в главном меню для подсказок
- **Выберите подходящий остров** - каждый остров имеет свою уникальную тематику
- **Сохраняйтесь часто** - используйте опцию "СОХРАНИТЬ ИГРУ" в главном меню
- **Экспериментируйте** - пробуйте разные классы и стратегии

### **🔧 Решение проблем:**
- **Игра не запускается** - проверьте установку Java 25 и JavaFX 25
- **Чёрный экран** - обновите видеодрайверы и проверьте поддержку OpenGL
- **Ошибки сохранения** - убедитесь что есть права на запись в папку игры
- **Медленная работа** - закройте другие программы и увеличите память JVM

## 🛠 Инструкция по запуску

### 1. Первичная настройка
Если вы запускаете проект впервые или на новом компьютере:
1.  Убедитесь, что файлы `OpenJDK25U-jdk_x64_windows_hotspot_25.0.2_10.msi` и `openjfx-25.0.2_windows-x64_bin-sdk.zip` находятся в папке проекта.
2.  Запустите **`setup-env.bat`** и дождитесь завершения.

### 2. Сборка и запуск (для разработки)
Чтобы применить изменения в коде и сразу увидеть их в игре:
*   Просто запустите **`build-and-run.bat`**.

### 3. Версия для друзей (Portable)
Чтобы поделиться игрой:
1.  Запустите **`create-portable.bat`**.
2.  Архивируйте папку `dist\Code-Travel-Portable`.
3.  Отправьте архив другу. Для запуска ему нужно нажать **`Start-Game.bat`**.
